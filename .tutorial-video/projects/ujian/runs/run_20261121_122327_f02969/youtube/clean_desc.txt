Video panduan resmi cara penggunaan fitur pada aplikasi UJIAN. Ikuti langkah-langkah mudah di bawah ini untuk memahami alur penggunaan secara lengkap.

📌 RINGKASAN LANGKAH-LANGKAH:
1. Login Siswa: Masuk ke halaman login siswa menggunakan username dan password peserta.
2. Dashboard Dan Pilih Ujian: Masuk ke dashboard dan pilih sesi ujian yang aktif.
3. Masukkan Token Ujian: Masukkan token resmi yang dirilis oleh pengawas / proktor.
4. Konfirmasi Dan Mulai Soal: Periksa rincian data peserta dan konfirmasi mulai ujian.
5. Antarmuka Cbt Dan Font: Kenali timer waktu, tombol ubah ukuran font (sedang/besar/sangat besar).
6. Menjawab Dan Navigasi: Pilih jawaban pernyataan Benar/Salah dan simpan.
7. Daftar Soal Dan Penutup: Akses drawer daftar nomor soal untuk berpindah ke nomor lainnya.

✨ FITUR UTAMA & KEUNGGULAN:
- Panduan interaktif visual beresolusi tinggi 1080x1920 (60 FPS).
- Navigasi responsif tampilan mobile smartphone.
- Terintegrasi langsung dengan database sistem CBT.
